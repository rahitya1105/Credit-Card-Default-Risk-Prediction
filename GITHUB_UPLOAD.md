# Put this project on GitHub

Suggested repository name: `credit-card-default-risk-prediction`

Suggested description: Credit card default risk analysis using Logistic Regression, Random Forest, hypothesis testing, and a Streamlit dashboard.

1. Extract `credit-card-default-risk-github.zip` on your computer.
2. Create a new GitHub repository with the name above, or a name you prefer.
3. In the repository, choose **uploading an existing file** or **Add file → Upload files**.
4. Upload the contents of the extracted folder so `README.md` and `app.py` are at the repository root. Include the `data` and `artifacts` folders. Upload the extracted files, not only the ZIP archive.
5. Commit the files. No credentials or API keys are needed by the application.

For Git-based uploads, the included `.gitignore` excludes local environments and temporary files while keeping the small trained model. The `.streamlit` folder sets the app theme and local port; `.vscode` contains optional editor tasks.

Included data and benchmark artifacts are public UCI data or outputs derived from it. Preserve the UCI attribution in README.md and LICENSE. The code is MIT licensed; the original dataset is CC BY 4.0.

Do not upload your local `.venv`, private financial records, or credentials. None are included in this package.

The README describes this as a historical research prototype. RESULTS.md contains the measured test metrics used in the resume claim.
